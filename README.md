# C-pattern-practice
This repository contains a growing collection of pattern printing programs in the C language. It focuses on strengthening logic building, mastering nested loops, and preparing for placement coding rounds.

🧠 Skills Practiced
* C Programming
* Control Structures (loops & conditions)
* Problem Solving
* Pattern Logic
* Placement Preparation

| Pattern No. | Description               | Sample Output Example       |
|-------------|---------------------------|-----------------------------|
| Pattern 1   | Star matrix               | `* * *`                     |
| Pattern 2   | Repeating characters      | `A A A`                     |
| Pattern 3   | Sequential alphabets      | `A B C`                     |
| Pattern 4   | Repeating numbers per row | `0 1 2`                     |
| Pattern 5   | Continuous numbers        | `1 2 3` then `4 5 6`        |
